
# ShelfSync - Library Management System

ShelfSync is a web-based Library Management System designed to make book and member management simple and efficient. It provides an easy-to-use interface for managing library records.

## Features

- View and manage books
- Add new books
- Edit and delete book records
- Search for books
- Manage library members
- Edit and delete member records
- Store data using browser localStorage
- Responsive and user-friendly interface

## Technologies Used

- HTML5 - Structure of the website
- CSS3 - Styling and layout
- JavaScript - Functionality and data management
- localStorage - Browser-based data persistence

## How to Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension or your browser.

## Data Storage

ShelfSync currently uses browser localStorage to store data. Records remain available in the same browser unless the stored data is cleared. Data is not automatically shared between different users or devices.
